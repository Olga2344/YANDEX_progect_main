## Аналитические SQL‑запросы (доноры, игра, книги, недвижимость)

В репозитории собраны четыре набора SQL‑запросов для анализа данных в разных предметных областях.

### Состав

- `Доноры.sql`  
  Аналитика сервиса донорства крови (`donorsearch.*`):
  - регионы с наибольшим числом доноров и донаций;
  - динамика донаций по месяцам;
  - влияние бонусной программы на активность;
  - вовлечение через соцсети и различие одноразовых/повторных доноров;
  - качество планирования донаций (сравнение план/факт).

- `игра.sql`  
  Аналитика free‑to‑play игры (`fantasy.*`):
  - платящие и неплатящие игроки, расходы и покупки;
  - популярность эпических предметов;
  - юнит‑экономика по расам персонажей;
  - частота покупок и сегментация игроков по активности.

- `Книги.sql`  
  Аналитика сервиса чтения/аудиокниг (Bookmate‑подобный, `source_db.*`, ClickHouse):
  - топ‑регионов по потреблению контента;
  - топ‑книг и авторов по времени прослушивания/чтения;
  - сегментация пользователей («слушатель», «читатель», «оба»);
  - использование по дням недели и форматам;
  - качество разметки книг по тегу «Магия»;
  - обновления мобильных приложений и коэффициент вариации сессий.

- `недвижимость.sql`  
  Аналитика рынка недвижимости СПб и Ленобласти (`real_estate.*`):
  - сроки экспозиции объявлений по сегментам (комнаты, апартаменты, этажность, балкон, парки/пруды);
  - сезонность публикации и снятия объявлений;
  - цена за м² и площадь по городам;
  - скорость продажи в разных населённых пунктах.
